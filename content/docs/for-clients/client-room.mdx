The **Client Room** is a single page that agencies set up for each client. It's the client's starting point and the place where onboarding happens.

## What's in it

- **Welcome:** a message from the agency.
- **Goals:** the decision and key numbers the work is aimed at, if the agency has set them.
- **Access checklist:** the accounts and access the agency needs, such as the website, Google, and each social platform.
- **Meetings:** upcoming meetings from the agency's calendar.
- **Your accounts:** quick links to the client's own accounts.
- **First 30 days:** what happens in the first month.
- **Team:** the people working on the account.
- **Documents:** shared files and links.

## The access checklist

The checklist is a two-way list:

1. The **client** marks each item as **provided**, with an optional note.
2. The **agency** confirms it was **received**, or marks it not applicable.

The progress bar shows how much of the setup is done. As items are completed, more of Verbolica unlocks for the client.

## For agencies: create a room

Open the brand and choose **Client Room** in the sidebar, then create the room. It starts with a standard access checklist, which you can edit. Use **Edit room** to change the welcome message, team, meetings, links and documents.
